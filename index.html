📖 操作说明 / User Guide

🚀 快速开始
1. 点右上角 ⚙️ 设置 → 填入 Alpaca API Key（免费注册 alpaca.markets）
2. 在顶部表单填入股票代码、数量、成本价 → 按 Enter 快速添加
3. 点 🔄 刷新 拉取实时报价
⌨️ 键盘快捷键
Tab — 在输入框之间跳转
Enter — 最后一栏（标签）按Enter直接提交添加
日期栏默认填入今天，无需手动输入
全局快捷键（不在输入框内时生效）：
Esc — 关闭当前弹窗
R — 刷新全部报价
1–9 — 快速切换到对应Tab（1=持仓，2=风险，3=配置...）
? — 打开本说明书
🏷 标签与筛选
添加持仓时在「标签 Tags」填入账户名（如 Schwab, IRA），多个用逗号分隔
筛选栏支持多选——同时点 IBKR + IRA 只看这两个账户的持仓
操作意向（🟢持有/📈加仓/🚫清仓等）通过每行右侧的 ⚙ 按钮设置
🛑 止损止盈
点行右侧 ⚙ 设置该股默认止损止盈 → 自动应用到所有批次
点行左侧 ▸ 展开批次明细 → 每笔可单独设定价格或开启跟踪止损
点 🎯 按钮根据设置参数自动计算止损止盈价
📊 各 Tab 功能
风险指标 — 点「计算风险指标」拉取历史K线计算 Beta/VaR/Sortino 等
资产配置 — 环形图 + 行业分布（点「加载行业数据」）
预警管理 — 设置止损止盈后，触及时自动发送浏览器通知 + 声音
历史交易 — 展开批次后点 ✕ 平仓，填入卖出价自动计算盈亏
盈亏分析 — 期间盈亏/Kelly仓位/月度日历/NAV走势（需积累快照）
股息 — 显示各持仓预计年/月股息收入，点「加载股息数据」初始化
财报 — 显示近期财报日期，⚡红色=7天内即将发布
💾 数据备份
点顶部 📦 导入/导出 → 定期下载 JSON 备份
所有数据存在浏览器 localStorage，清除缓存会丢失数据，务必定期备份
换设备/换浏览器时用「恢复JSON备份」恢复所有数据

Alpaca（必须）：免费注册 alpaca.markets，用于实时报价和历史K线
